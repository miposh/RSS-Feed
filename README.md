# RSS Feed Bot

Телеграм-бот для отслеживания RSS-лент и отправки обновлений в чаты.

## Возможности

- Добавление/удаление RSS-лент
- Просмотр списка добавленных лент
- Автоматическая проверка обновлений
- Отправка новых записей в чат

## Команды

- `/start` - перезапуск бота
- `/add` - добавить RSS-ленту
- `/list` - показать список RSS-лент
- `/remove` - удалить RSS-ленту

## Установка

1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Создать файл `.env` с переменными окружения:
   ```
   BOT_TOKEN=ваш_токен_бота
   ```
4. Запустить бота: `python -m src.bot`

## Обновления

### 21.07.2025 - Исправление проблем с некоторыми RSS-лентами

- Заменена библиотека `aiohttp` на `requests` для загрузки RSS-лент
- Исправлена проблема с обработкой chunked transfer encoding
- Добавлено отключение SSL-верификации для совместимости с некоторыми серверами
- Улучшена обработка ошибок при загрузке лент
- Добавлена обработка некорректных CDATA-секций в XML

Эти изменения решают проблему с добавлением лент с сайтов, использующих нестандартную реализацию chunked transfer encoding и содержащих некорректно сформированный XML, например, rozetked.me.

### Инструменты для тестирования

В репозитории доступны два скрипта для тестирования RSS-лент:

- `test_feed.py` - простой тест с использованием библиотеки requests
- `test_rss_feed.py` - расширенный тест с подробным выводом информации о ленте

Пример использования:

```bash
./test_rss_feed.py https://example.com/rss.xml
```
